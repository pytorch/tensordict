tensordict: containers and functions#

This page lists the tensordict containers, and the methods that they all share, grouped by task. Each group also lists the functions of the tensordict module for its task. A TensorDict is a dict[str, torch.Tensor] that behaves like one tensor. Its entries share their leading dimensions, the batch size, and an operation such as indexing, reshaping, or to() applies to every entry. For an introduction, see What is TensorDict?.

Containers#

TensorDictBase is the abstract base class of all tensordicts. Its subclasses keep their entries in different places:

  • TensorDict keeps its tensors in memory. It is the default container.

  • LazyStackedTensorDict is a stack of tensordicts that keeps each tensordict separate, so that their entries can have different shapes. See Stacking and variable-size data.

  • PersistentTensorDict reads and writes its entries in an HDF5 or zarr file. See Large datasets and storage backends.

  • TensorDictParams is a tensordict and a torch.nn.Module. If a module holds one, the parameters and buffers of the module include its tensors.

MemoryMappedTensor is not a tensordict. It is a tensor whose data is in a file, and the type of the entries of a memory-mapped tensordict.

TensorCollection is the common base class of the tensordicts and the subclasses of TensorClass: the type hint for “a tensordict or a tensorclass”.

Other containers have their own pages: TensorClass, the class form with typed fields and methods, and non-tensor data (tensorclass and non-tensor data), TypedTensorDict (TypedTensorDict), and the key-value stores (Key-value stores and UCXX). To choose one, see Which container should I use?.

Methods by task#

The tables below list the methods of TensorDictBase, with one page for each method. Every tensordict class and every tensorclass has these methods. A class page lists only the methods that the class adds, and the overrides that have their own documentation. When the tensordict module has a function for the same task, the function is in the same group.

Construction and conversion#

Create a tensordict from Python, numpy, or pandas data, and convert a tensordict to other types. Most from_* class methods have a function of the same name in the tensordict module. To read a tensordict from a file, see Saving, loading, and file formats. For the arguments of the constructor, see TensorDict.

Keys, values, and entries#

Read, write, select, and rename the entries of a tensordict. A key is a string, or a tuple of strings that points to an entry of a nested tensordict. NestedKey is the type of these keys. For the rules, see Keys, nested keys, and locking. For values that are not tensors, see Non-tensor data and unbatched entries.

Locking#

A locked tensordict raises an error if you add, replace, rename, or delete an entry. In-place writes with set_ and update_ still work, also for non-tensor entries. unlock_ also works in a with block: the tensordict is locked again at the end of the block. See Keys, nested keys, and locking.

TensorDictBase.lock_()

Locks the tensordict and its nested tensordicts, and returns it.

TensorDictBase.unlock_()

Unlocks the tensordict and its nested tensordicts, and returns it.

TensorDictBase.is_locked

True if the tensordict is locked.

Distributed and remote#

Send and receive tensordicts between processes with torch.distributed, run collective operations on them, and stream them over UCXX (see Key-value stores and UCXX). See Distributed tensordicts.

TensorDictBase.send([dst, group, group_dst, ...])

Sends the leaves of the tensordict to another rank, with torch.distributed.

TensorDictBase.recv([src, group, group_src, ...])

Receives the leaves that send() sends, and writes them into the tensordict in place.

TensorDictBase.isend([dst, group, ...])

Sends the leaves of the tensordict to another rank, one asynchronous transfer per leaf.

TensorDictBase.irecv([src, group, ...])

Receives the leaves that isend() or send() sends, one asynchronous transfer per leaf.

TensorDictBase.all_reduce([op, group, async_op])

Reduces each leaf over all the ranks of the group, in place, so that every rank holds the result.

TensorDictBase.reduce(dst[, op, async_op, ...])

Reduces each leaf over all the ranks of the group, into the tensordict of rank dst.

TensorDictBase.broadcast(src, *[, group, ...])

Sends the tensordict of rank src to every rank of the group, and returns it on each rank.

TensorDictBase.scatter(src[, tensordicts, ...])

Scatters a list of tensordicts from src to all ranks.

TensorDictBase.all_gather(*[, group])

Returns a list with the tensordict of each rank of the group, on every rank.

TensorDictBase.gather_and_stack(dst[, group])

Stacks the tensordicts of the other ranks into the tensordict of rank dst, in place.

TensorDictBase.init_remote([dst, group, ...])

Sends the structure and the content of the tensordict to a rank that does not know them.

TensorDictBase.from_remote_init(src[, ...])

Receives a tensordict that init_remote() sends, and returns it.

TensorDictBase.asend(dst)

Sends the tensordict through a UCXX pipe, asynchronously.

TensorDictBase.arecv(src, *[, device])

Receives a tensordict from a UCXX pipe, into the tensordict if possible, asynchronously.

Package constants#

tensordict.KEY_SEPARATOR#

".", the default separator of flatten_keys() and unflatten_keys(), for code that joins or splits nested keys the same way, such as tuple(name.split(KEY_SEPARATOR)). The names of state_dict() also use ".", the torch.nn.Module convention, independently of this constant. Reassigning it has no effect: the defaults are bound when the methods are defined. It can also be imported from tensordict.utils.

tensordict.base.NO_DEFAULT#

The sentinel that marks an argument as not given where None is a valid value, such as default in get_non_tensor() or device in new_zeros(). It can also be imported from tensordict.tensordict.

tensordict.__version__#

The version string of the installed tensordict package, or None if it cannot be determined, for example when tensordict is imported from a source tree that is not installed.

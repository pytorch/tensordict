# TensorDictBase.tanh

TensorDictBase.tanh_() → Self

Applies [`torch.tanh()`](https://docs.pytorch.org/docs/stable/generated/torch.tanh.html#torch.tanh) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

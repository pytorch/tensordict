# TensorDictBase.isposinf

TensorDictBase.isposinf() → Self

Returns a new tensordict with [`torch.isposinf()`](https://docs.pytorch.org/docs/stable/generated/torch.isposinf.html#torch.isposinf) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

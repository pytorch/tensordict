# TensorDictBase.acos

TensorDictBase.acos() → Self

Returns a new tensordict with [`torch.acos()`](https://docs.pytorch.org/docs/stable/generated/torch.acos.html#torch.acos) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

# TensorDictBase.shape

*property*TensorDictBase.shape*: [Size](https://docs.pytorch.org/docs/stable/size.html#torch.Size)*

the same as [`batch_size`](tensordict.TensorDictBase.batch_size.html#tensordict.TensorDictBase.batch_size).

Assigning it sets the batch size.

Type:

The batch size of the tensordict, as a [`torch.Size`](https://docs.pytorch.org/docs/stable/size.html#torch.Size)

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

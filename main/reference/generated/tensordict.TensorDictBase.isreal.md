# TensorDictBase.isreal

TensorDictBase.isreal() → Self

Returns a new tensordict with [`torch.isreal()`](https://docs.pytorch.org/docs/stable/generated/torch.isreal.html#torch.isreal) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

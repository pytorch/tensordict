# TensorDictBase.tan

TensorDictBase.tan_() → Self

Applies [`torch.tan()`](https://docs.pytorch.org/docs/stable/generated/torch.tan.html#torch.tan) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

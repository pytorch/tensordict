# TensorDictBase.expm1

TensorDictBase.expm1_() → Self

Applies [`torch.expm1()`](https://docs.pytorch.org/docs/stable/generated/torch.expm1.html#torch.expm1) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

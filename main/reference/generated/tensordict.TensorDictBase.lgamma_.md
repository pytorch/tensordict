# TensorDictBase.lgamma

TensorDictBase.lgamma_() → Self

Computes the [`lgamma()`](https://docs.pytorch.org/docs/stable/generated/torch.lgamma.html#torch.lgamma) value of each element of the TensorDict in-place.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

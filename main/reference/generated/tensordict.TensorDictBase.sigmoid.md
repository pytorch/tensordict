# TensorDictBase.sigmoid

TensorDictBase.sigmoid() → Self

Returns a new tensordict with [`torch.sigmoid()`](https://docs.pytorch.org/docs/stable/generated/torch.sigmoid.html#torch.sigmoid) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

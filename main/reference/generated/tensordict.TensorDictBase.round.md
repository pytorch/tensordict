# TensorDictBase.round

TensorDictBase.round() → Self

Returns a new tensordict with [`torch.round()`](https://docs.pytorch.org/docs/stable/generated/torch.round.html#torch.round) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

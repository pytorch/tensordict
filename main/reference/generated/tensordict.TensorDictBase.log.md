# TensorDictBase.log

TensorDictBase.log() → Self

Returns a new tensordict with [`torch.log()`](https://docs.pytorch.org/docs/stable/generated/torch.log.html#torch.log) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

# TensorDictBase.sin

TensorDictBase.sin() → Self

Returns a new tensordict with [`torch.sin()`](https://docs.pytorch.org/docs/stable/generated/torch.sin.html#torch.sin) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

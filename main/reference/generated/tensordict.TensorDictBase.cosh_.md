# TensorDictBase.cosh

TensorDictBase.cosh_() → Self

Computes the [`cosh()`](https://docs.pytorch.org/docs/stable/generated/torch.cosh.html#torch.cosh) value of each element of the TensorDict in-place.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

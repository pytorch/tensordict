# TensorDictBase.sinh

TensorDictBase.sinh_() → Self

Computes the [`sinh()`](https://docs.pytorch.org/docs/stable/generated/torch.sinh.html#torch.sinh) value of each element of the TensorDict in-place.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

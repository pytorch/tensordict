TensorClass#

TensorClass has the methods of TensorDictBase, listed by task in Methods by task. This page lists only the methods that TensorClass adds, and the overrides that have their own documentation.

class tensordict.TensorClass(*args, **kwargs)#

Bases: TensorCollection

A base class for dataclass-like containers of tensors.

Subclass TensorClass and annotate fields, as with dataclasses.dataclass(). The instances behave like a TensorDict: they have a batch size, and they support indexing, reshaping, to(device), torch.stack(), torch.cat() and memory-mapping. A field can hold a tensor, a tensordict, another tensorclass, or any Python object (stored as NonTensorData). This class replaces the tensorclass() decorator, which is kept for existing code.

Use a tensorclass instead of a TensorDict when the data has a fixed set of named fields, when you want editors and type checkers to know the fields, or when you want to add methods. Use a TypedTensorDict instead if you need a TensorDictBase subclass (state["key"], **state unpacking). Which container should I use? compares the containers, and TensorClass is the user guide.

The constructor of a subclass takes the fields, by name or in order, and these keyword arguments: Foo(tensor=..., batch_size=[3]).

Keyword Arguments:

  • batch_size (Size or list of int, optional) – the batch size of the instance: the leading dimensions that all its fields share. See Batch size, shapes, and indexing. Defaults to torch.Size([]).

  • device (device, str or int, optional) – the device of the instance. Tensors on another device are moved to it. Defaults to None, which leaves each tensor where it is.

  • names (list of str, optional) – the names of the batch dimensions, one per dimension. Defaults to None.

  • lock (bool, optional) – if True, the instance is locked: writing a field raises a RuntimeError. See Locking and temporary changes. Defaults to False.

The class flags below go to the class definition instead.

Class flags

A flag changes the behavior of every instance of the class. Set it in one of three equivalent forms:

>>> import torch
>>> from tensordict import TensorClass, tensorclass
>>> class Foo(TensorClass["autocast"]):     # bracket form
...     integer: int
>>> class Foo(TensorClass, autocast=True):  # keyword form
...     integer: int
>>> @tensorclass(autocast=True)             # legacy decorator form
... class Foo:
...     integer: int

To combine flags, list them in the brackets:

>>> class Foo(TensorClass["nocast", "frozen"]):
...     integer: int

The flags are:

  • No flag: tensor-compatible values (int, float, np.ndarray) are cast to tensors. Other values are stored as NonTensorData.

    >>> class Foo(TensorClass):
...     x: int
>>> Foo(x=1).x
tensor(1)

  • autocast: when a field is set, the value is converted to the annotated type. For example, an int field set to torch.ones(()) holds 1.

    >>> class Foo(TensorClass["autocast"]):
...     x: int
>>> Foo(x=torch.ones(())).x
1

  • nocast: tensor-compatible values are stored as they are, not cast to tensors.

    >>> class Foo(TensorClass["nocast"]):
...     x: int
>>> Foo(x=1).x
1

  • tensor_only: every field annotation must be a tensor type, a tensor collection, or an optional or union of these. Other annotations raise a TypeError when the class is defined. Values that can be cast to a tensor (Python scalars, numpy arrays) are cast. Reading a field then skips the lookup in the non-tensor storage.

    >>> class Foo(TensorClass["tensor_only"]):
...     x: torch.Tensor
>>> Foo(x=1).x
tensor(1)

  • frozen: assigning a field raises FrozenInstanceError, as with @dataclass(frozen=True). Subclasses of a frozen class are frozen too. A frozen class cannot subclass a non-frozen tensorclass: this raises a TypeError.

    >>> class Foo(TensorClass["frozen"]):
...     x: torch.Tensor
>>> foo = Foo(x=torch.zeros(3))
>>> foo.x = torch.ones(3)
Traceback (most recent call last):
  ...
dataclasses.FrozenInstanceError: cannot assign to field 'x'

  • shadow: by default, a field whose name is a tensorclass member (batch_size, device, names, sum, apply and the other TensorDict methods) raises an AttributeError when the class is defined. shadow=True allows these names. The field then hides the member of the same name.

    >>> class Foo(TensorClass["shadow"]):
...     sum: torch.Tensor
>>> Foo(sum=torch.ones(3), batch_size=[3]).sum
tensor([1., 1., 1.])

  • skip_post_init_on_rebuild: __post_init__ runs on the data that comes in (the generated __init__, from_tensordict, from_dict, the other constructors such as from_any or fromkeys, and loads), but not when tensordict makes a new instance from an existing one (indexing, clone, to, apply, stacking and the other operations). Subclasses inherit the flag.

    >>> class Foo(TensorClass["skip_post_init_on_rebuild"]):
...     x: torch.Tensor
...     def __post_init__(self):
...         print("checked")
>>> foo = Foo(x=torch.zeros(3))
checked
>>> foo = foo.clone()

autocast, nocast and tensor_only are exclusive: combining two of them raises a TypeError.

A class keyword that is not a flag, cast_filter, sets the default cast_filter of to() and of the dtype shorthands (float(), bfloat16(), …): a predicate fn(key, value) -> bool that selects the tensor leaves a dtype cast applies to. A cast_filter passed to the call overrides it, and cast_filter=None there casts every leaf. Subclasses inherit it. It applies to calls on the tensorclass itself, not when the tensorclass is a value of another tensordict or tensorclass that is cast.

>>> from tensordict import is_inexact
>>> class Mesh(TensorClass, cast_filter=is_inexact):
...     points: torch.Tensor
...     cells: torch.Tensor
>>> mesh = Mesh(points=torch.zeros(4, 3), cells=torch.zeros(2, 3, dtype=torch.long))
>>> mesh.bfloat16().points.dtype, mesh.bfloat16().cells.dtype
(torch.bfloat16, torch.int64)

Subclassing

A class with flags is a regular class. You can subclass it and add flags:

>>> class Base(TensorClass["autocast"]):
...     x: int
>>> class Sub(Base, shadow=True):   # autocast inherited, shadow added
...     y: float

Type checking

TensorClass[...] is implemented with __class_getitem__(), so pyright resolves it to the class with flags, not to a generic parameter. Mypy does not evaluate __class_getitem__ in a list of base classes and rejects the bracket form. In code that mypy checks, use the keyword form: class Foo(TensorClass, autocast=True). Editors complete the annotated fields on instances.

Note

TensorClass itself is not a tensorclass: only its subclasses become dataclasses. The reason is that a non-frozen base cannot have a frozen subclass, and the base cannot know whether a subclass sets frozen.

See also

  • tensorclass() for the decorator form.

  • from_dataclass() to migrate an existing @dataclass to a tensorclass.

  • TensorClassModuleBase for typed nn.Module I/O backed by tensorclasses.

Examples

>>> from typing import Any
>>> import torch
>>> from tensordict import TensorClass
>>> class Foo(TensorClass):
...     tensor: torch.Tensor
...     non_tensor: Any
...     nested: Any = None
>>> foo = Foo(tensor=torch.zeros(3), non_tensor="a string!", batch_size=[3])
>>> print(foo)
Foo(
    non_tensor=NonTensorData(data=a string!, batch_size=torch.Size([3]), device=None),
    tensor=Tensor(shape=torch.Size([3]), device=cpu, dtype=torch.float32, is_shared=False),
    nested=None,
    batch_size=torch.Size([3]),
    device=None,
    is_shared=False)
>>> foo[0].non_tensor
'a string!'
>>> foo.reshape(1, 3).batch_size
torch.Size([1, 3])
classmethod from_dict(input_dict, *, auto_batch_size: bool | None = None, batch_size=None, device=None, batch_dims=None)#

Builds an instance of the tensorclass from a dictionary of its fields.

The fields that input_dict misses are set to None, also those that declare a default or a default factory. Starting with TensorDict 0.17, the default will change to filling these fields with their defaults, as the constructor does. Until then, a call that misses such a field warns with a FutureWarning.

Parameters:

input_dict (dict) – the values of the fields. Nested dictionaries become tensordicts, or tensorclasses for the fields annotated with one.

Keyword Arguments:

  • auto_batch_size (bool, optional) – if True, sets the batch size to the largest leading shape that all the entries share. Defaults to None, which behaves like False, unless batch_dims is passed: then it behaves like True.

  • batch_size (Size or list of int, optional) – the batch size of the result: the leading dimensions that all its entries share. Defaults to None, which gives an empty batch size unless auto_batch_size is on.

  • device (device, str or int, optional) – the device of the result. Leaves on another device are moved to it. Defaults to None, which leaves each leaf where it is.

  • batch_dims (int, optional) – with auto_batch_size, the maximum number of batch dimensions. Exclusive with batch_size. Defaults to None.

Returns:

A new instance of the class.

Examples

>>> import torch
>>> from tensordict import TensorClass
>>> class Foo(TensorClass):
...     x: torch.Tensor
...     y: torch.Tensor
>>> foo = Foo.from_dict({"x": torch.zeros(3, 4), "y": torch.zeros(3)}, auto_batch_size=True)
>>> foo.batch_size
torch.Size([3])
from_tensordict(tensordict: TensorDictBase, non_tensordict: dict | None = None, safe: bool | None = None) → Self#

Wraps a tensordict in a new instance of the tensorclass, without copying the leaves.

If tensordict is a TensorDict, the entries of the fields annotated with a tensorclass (or Optional of one) that are tensordicts become instances of that tensorclass, recursively. They are set in a shallow copy of tensordict, which keeps its own entries. An entry with keys that the annotated class does not declare stays a tensordict. Other backends are wrapped as they are: setting a tensorclass in them would write to their storage (e.g. an H5 file).

Parameters:

  • tensordict (TensorDictBase) – the tensordict that holds the tensor fields.

  • non_tensordict (dict, optional) – the values of the non-tensor fields. The fields that neither argument holds are set to None. Defaults to None.

  • safe (bool, optional) – deprecated in 0.15, will be removed in TensorDict 0.17. If False, skips the check that tensordict is a TensorDictBase. By default, the check runs, and another type raises a RuntimeError.

Returns:

A new instance of the class, whose fields are the entries of tensordict.

Examples

>>> import torch
>>> from tensordict import TensorClass
>>> class Pose(TensorClass):
...     q: torch.Tensor
>>> class Obs(TensorClass):
...     a: Pose
>>> obs = Obs(a=Pose(q=torch.zeros(5, 4), batch_size=[5]), batch_size=[5])
>>> type(Obs.from_tensordict(obs.to_tensordict()).a).__name__
'Pose'
get(key: NestedKey, *args, **kwargs)#

Returns the value of a field, or default if the key is missing.

tc.get("x") is the same as tc.x: a non-tensor field returns the Python object, not a NonTensorData. The keyword arguments of get() (as_list, as_padded_tensor, …) are passed to the tensordict that holds the fields.

A nested key that runs through a tensor field, such as tc.get(("x", "y")) for a tensor x, returns None and warns. Starting with TensorDict 0.17, the default will change to raising the ValueError that get() raises. A default passed explicitly, as in tc.get(("x", "y"), None), is returned without a warning.

Parameters:

  • key (NestedKey) – the key to read. A tuple reads an entry of a nested field: tc.get(("a", "b")) is tc.a.get("b").

  • default (optional) – the value returned if the key is missing. Defaults to None.

Examples

>>> import torch
>>> from tensordict import TensorClass
>>> class Foo(TensorClass):
...     x: torch.Tensor
...     name: str
>>> foo = Foo(x=torch.zeros(3), name="a", batch_size=[3])
>>> foo.get("name")
'a'
>>> foo.get("z", "missing")
'missing'
load_memmap_(prefix: str | Path, robust_key: bool | None = True, *, allow_pickle: bool | None = None, mode: str | None = None)#

Loads a memory-mapped tensorclass into this instance, and returns self.

Works as load_memmap_(), and also loads the non-tensor fields.

Parameters:

  • prefix (str or Path) – the directory, or the ".tdz" archive file, to read.

  • robust_key (bool, optional) – the key encoding used when the data was saved. See memmap(). Defaults to True.

Keyword Arguments:

  • allow_pickle (bool, optional) – whether pickled non-tensor fields may be loaded. See load_memmap(). Defaults to None, which loads pickled fields with a FutureWarning.

  • mode (str, optional) – the mode of the memory maps. See load_memmap(). Defaults to None.

load_state_dict(state_dict: dict[str, Any], strict=True, assign=False, from_flatten=None)#

Loads a state dict made by state_dict() into the tensorclass, and returns self.

Works as load_state_dict(), which describes the arguments, and also loads the non-tensor fields. It also reads the state dicts of older versions, which hold "_tensordict" and "_non_tensordict" entries.

Examples

>>> import torch
>>> from tensordict import TensorClass
>>> class Foo(TensorClass):
...     x: torch.Tensor
...     name: str
>>> sd = Foo(x=torch.zeros(3), name="a", batch_size=[3]).state_dict()
>>> foo = Foo(x=torch.ones(3), name="b", batch_size=[3])
>>> _ = foo.load_state_dict(sd)
>>> foo.x, foo.name
(tensor([0., 0., 0.]), 'a')
set(key: NestedKey, value: Any, inplace: bool = False, non_blocking: bool = False)#

Sets a field, and returns the tensorclass.

tc.set("x", value) is the same as tc.x = value: the value is cast according to the class flags (see TensorClass). Otherwise, it works as set().

Parameters:

  • key (NestedKey) – the field to set. A tuple sets an entry of a nested field: tc.set(("a", "b"), value) is tc.a.set("b", value).

  • value (Any) – the value of the field.

  • inplace (bool, optional) – if True and the field holds a tensor, the value is copied into it, which keeps its storage. Defaults to False. See In-place operations.

  • non_blocking (bool, optional) – if True, copies between devices can run asynchronously with respect to the host. Defaults to False.

Returns:

self.

Raises:

  • AttributeError – if key is not a field of the class.

  • RuntimeError – if the tensorclass is locked, also with inplace=True.

Examples

>>> import torch
>>> from tensordict import TensorClass
>>> class Foo(TensorClass):
...     x: torch.Tensor
>>> foo = Foo(x=torch.zeros(3), batch_size=[3])
>>> foo.set("x", torch.ones(3)).x
tensor([1., 1., 1.])
>>> foo.set("z", torch.ones(3))
Traceback (most recent call last):
    ...
AttributeError: Cannot set the attribute 'z': Foo has no such field. Its fields are ['x'].
state_dict(destination=None, prefix='', keep_vars=False, flatten=True) → dict[str, Any]#

Returns the state dict of the tensorclass.

Works as state_dict(), which describes the arguments. The tensor fields are the entries of the state dict. The non-tensor fields and the name of the class go to the _metadata attribute, under the "_non_tensor" and "_type" keys of their level.

Examples

>>> import torch
>>> from tensordict import TensorClass
>>> class Foo(TensorClass):
...     x: torch.Tensor
...     name: str
>>> foo = Foo(x=torch.zeros(3), name="a", batch_size=[3])
>>> sd = foo.state_dict()
>>> list(sd.keys())
['x']
>>> sd._metadata[""]["_non_tensor"]
{'name': 'a'}
to_tensordict(*, retain_none: bool | None = None) → TensorDict#

Returns a TensorDict with a copy of the fields of the tensorclass.

The tensors are copied, and memory-mapped or shared tensors become regular tensors. Nested tensorclasses become tensordicts, and non-tensor fields become NonTensorData entries.

Keyword Arguments:

retain_none (bool, optional) – if True, fields set to None are written as None entries. Defaults to None, which drops them.

Examples

>>> from typing import Any
>>> import torch
>>> from tensordict import TensorClass
>>> class Foo(TensorClass):
...     x: torch.Tensor
...     y: Any = None
>>> foo = Foo(x=torch.zeros(3))
>>> sorted(foo.to_tensordict().keys())
['x']
>>> sorted(foo.to_tensordict(retain_none=True).keys())
['x', 'y']
unbind(dim: int)#

Returns a tuple of tensorclasses, one per index along a batch dimension.

Works as unbind(): the results share the storage of the tensorclass.

Parameters:

dim (int) – the batch dimension to remove.

Examples

>>> import torch
>>> from tensordict import TensorClass
>>> class Foo(TensorClass):
...     x: torch.Tensor
>>> foo = Foo(x=torch.arange(6).reshape(2, 3), batch_size=[2, 3])
>>> [item.x for item in foo.unbind(1)]
[tensor([0, 3]), tensor([1, 4]), tensor([2, 5])]
update_(input_dict_or_td: dict[str, Tensor | TensorCollection] | T | None = None, clone: bool = False, inplace: bool = False, *, keys_to_update: Sequence[NestedKey] | None = None, non_blocking: bool = False, **kwargs)#

Copies the entries of a dictionary, a tensordict or a tensorclass into the existing entries.

Returns self. Works as update_(), which describes the arguments: the existing tensors keep their storage. The fields can also be passed as keyword arguments, tc.update_(x=value). inplace has no effect.

A tensorclass or dict source ignores clone, non_blocking and keys_to_update: the entries that keys_to_update leaves out are written too, and the call warns. Starting with TensorDict 0.17, the default will change to writing only the entries in keys_to_update, as for a TensorDict source.

Examples

>>> import torch
>>> from tensordict import TensorClass
>>> class Foo(TensorClass):
...     x: torch.Tensor
>>> foo = Foo(x=torch.zeros(3), batch_size=[3])
>>> x = foo.x
>>> _ = foo.update_({"x": torch.ones(3)})
>>> x
tensor([1., 1., 1.])
update_at_(input_dict_or_td: dict[str, Tensor | TensorCollection] | T, idx: None | int | slice | str | Tensor | List[Any] | Tuple[Any, ...], clone: bool = False, *, keys_to_update: Sequence[NestedKey] | None = None, non_blocking: bool = False)#

Writes the entries of a dictionary, a tensordict or a tensorclass in place at an index, and returns self.

Works as update_at_(), which describes the arguments, with one difference. A tensorclass or dict source that update() accepts, such as one with the batch size of the tensorclass, goes to update() instead: its entries replace those of the tensorclass whatever the index, and the call warns. Starting with TensorDict 0.17, the default will change to writing such a source in place at the index, as update_at_() does.

# TensorDictBase.sign

TensorDictBase.sign_() → Self

Computes the [`sign()`](https://docs.pytorch.org/docs/stable/generated/torch.sign.html#torch.sign) value of each element of the TensorDict in-place.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

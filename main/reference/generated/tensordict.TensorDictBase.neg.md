# TensorDictBase.neg

TensorDictBase.neg() → Self

Computes the [`neg()`](https://docs.pytorch.org/docs/stable/generated/torch.neg.html#torch.neg) value of each element of the TensorDict.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

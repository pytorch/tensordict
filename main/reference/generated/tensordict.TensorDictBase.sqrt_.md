# TensorDictBase.sqrt

TensorDictBase.sqrt_() → Self

Applies [`torch.sqrt()`](https://docs.pytorch.org/docs/stable/generated/torch.sqrt.html#torch.sqrt) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

# TensorDictBase.reciprocal

TensorDictBase.reciprocal() → Self

Returns a new tensordict with [`torch.reciprocal()`](https://docs.pytorch.org/docs/stable/generated/torch.reciprocal.html#torch.reciprocal) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

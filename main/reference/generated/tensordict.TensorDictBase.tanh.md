# TensorDictBase.tanh

TensorDictBase.tanh() → Self

Computes the [`tanh()`](https://docs.pytorch.org/docs/stable/generated/torch.tanh.html#torch.tanh) value of each element of the TensorDict.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

# TensorDictBase.atan

TensorDictBase.atan() → Self

Returns a new tensordict with [`torch.atan()`](https://docs.pytorch.org/docs/stable/generated/torch.atan.html#torch.atan) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

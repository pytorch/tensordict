# TensorDictBase.exp

TensorDictBase.exp_() → Self

Applies [`torch.exp()`](https://docs.pytorch.org/docs/stable/generated/torch.exp.html#torch.exp) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

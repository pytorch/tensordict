# TensorDictBase.log

TensorDictBase.log_() → Self

Computes the [`log()`](https://docs.pytorch.org/docs/stable/generated/torch.log.html#torch.log) value of each element of the TensorDict in-place.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

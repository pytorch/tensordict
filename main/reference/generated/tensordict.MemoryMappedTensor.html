MemoryMappedTensor#

class tensordict.MemoryMappedTensor(source, *, dtype=None, shape=None, index=None, device=None, handler=None, filename=None)#

Bases: Tensor

A CPU tensor whose storage is a file on disk, or anonymous shared memory when no filename is given.

Use it to share a tensor between processes, or to work with data that is larger than RAM: the operating system reads from the file only the pages that you access. When a MemoryMappedTensor is sent through a multiprocessing queue or an RPC call, only its file or shared-memory reference is sent, not the data. memmap() turns every leaf of a tensordict into a MemoryMappedTensor. See Save and load tensordicts and Load data and share it between processes.

Build one with a class method rather than with the constructor:

  • from_tensor() copies a tensor;

  • empty(), zeros(), ones() and full() make a new tensor of a given shape, and empty_like(), zeros_like(), ones_like() and full_like() one with the shape and dtype of another tensor;

  • from_filename() maps an existing file, and from_storage() wraps an existing storage.

The methods that write new data take a filename: with one, the data is in that file; without one, it is in anonymous shared memory, and filename raises an error. Indexing a MemoryMappedTensor, unbind(), chunk() and split() give MemoryMappedTensors on the same storage. Other operations (x + 1, for example) give a regular torch.Tensor.

A MemoryMappedTensor has these constraints:

  • It must be on CPU, and it cannot require gradients.

  • With RPC, every node must have read access to the file path. If it does not, the result of sending the tensor is undefined.

Warning

A caller that supplies filename must control its parent directory. Existing symbolic links are rejected, but path-based memory mapping cannot prevent another process with directory write access from replacing a path after it has been validated.

The handler argument is internal.

Parameters:

source (Tensor, TypedStorage, UntypedStorage or str) – the data. A str is the name of an existing file, mapped as from_filename() does with dtype, shape and index. With filename, the tensor is copied to that file, as from_tensor() does. A storage is passed to from_storage() with the other arguments. A tensor without filename is wrapped as it is: the result shares its memory but has no file or shared-memory handle, so it cannot be pickled.

Keyword Arguments:

  • dtype (dtype, optional) – with a str source, the dtype of the data in the file (required). With a storage, the dtype of the tensor, as in from_storage(). Not accepted with the filename keyword. Defaults to None.

  • shape (Size, optional) – the shape of the result, as in from_filename(), from_tensor() or from_storage(); required with a str source. Ignored for a tensor without filename. Defaults to None, which keeps the shape of source.

  • index (index, optional) – an index applied to the result, as in tensor[index]. With a str or storage source, shape is the shape of the data before index is applied. Defaults to None.

  • device (device, str or int, optional) – None or "cpu"; another device raises a ValueError. Defaults to None.

  • filename (str or Path, optional) – the file to copy source to. Defaults to None.

Examples

>>> import os
>>> import tempfile
>>> import torch
>>> from tensordict import MemoryMappedTensor
>>> with tempfile.TemporaryDirectory() as tmpdir:
...     filename = os.path.join(tmpdir, "x.memmap")
...     x = MemoryMappedTensor.from_tensor(torch.arange(4.0), filename=filename)
...     x[0] = 10.0  # writes to the file
...     print(MemoryMappedTensor.from_filename(filename, dtype=torch.float32, shape=(4,)))
MemoryMappedTensor([10.,  1.,  2.,  3.])

Without a filename, the data is in anonymous shared memory:

>>> z = MemoryMappedTensor.zeros(2, 3)
>>> z.shape, z.dtype
(torch.Size([2, 3]), torch.float32)
>>> type(z[0]).__name__, type(z + 1).__name__
('MemoryMappedTensor', 'Tensor')
chunk(chunks, dim=0)#

Splits the tensor into chunks views, as torch.Tensor.chunk() does.

The chunks are MemoryMappedTensors on the same storage, so they keep the file and can be pickled. Under torch.compile(), they are regular tensors.

classmethod from_filename(filename, dtype, shape, index=None, mode: str | None = None)#

Returns a MemoryMappedTensor that maps an existing file.

The file holds raw data with no header, so the dtype and the shape must be given. memmap() records them in the meta.json file of the directory it writes.

Parameters:

  • filename (str or Path) – the path to the file.

  • dtype (dtype) – the dtype of the data.

  • shape (Size, sequence of int or Tensor) – the shape of the tensor. A 2-D tensor gives a nested tensor, with the shape of each element in one row.

  • index (index, optional) – an index applied to the result, as in tensor[index]. Defaults to None.

  • mode (str, optional) – "r" maps the file copy-on-write: in-place writes stay in memory. "r+" maps it shared: in-place writes reach the file, and a PermissionError is raised if the file is not writable. Defaults to None, which maps the file shared if it is writable and copy-on-write otherwise.

Raises:

  • ValueError – if mode is not None, "r" or "r+".

  • PermissionError – if mode="r+" and the file is not writable.

Examples

>>> import os
>>> import tempfile
>>> import torch
>>> from tensordict import MemoryMappedTensor
>>> with tempfile.TemporaryDirectory() as tmpdir:
...     filename = os.path.join(tmpdir, "x.memmap")
...     _ = MemoryMappedTensor.from_tensor(torch.arange(6), filename=filename)
...     x = MemoryMappedTensor.from_filename(filename, torch.int64, (2, 3), mode="r")
...     x[0, 0] = 100  # copy-on-write: the file is unchanged
...     print(MemoryMappedTensor.from_filename(filename, torch.int64, (2, 3)))
MemoryMappedTensor([[0, 1, 2],
                    [3, 4, 5]])

classmethod from_storage(storage, *, shape: Size | None = None, dtype: dtype | None = None, device: device | None = None, index: IndexType | None = None, filename: Path | str = None, handler: _handler = None)#

Returns a MemoryMappedTensor that views an existing storage.

The data is not copied: writes to the result change the storage. If the storage was mapped from a file (for example with torch.UntypedStorage.from_file()), the result keeps that file and can be pickled; other storages give a tensor that cannot be pickled.

Parameters:

storage (UntypedStorage or TypedStorage) – the storage to view.

Keyword Arguments:

  • shape (Size or Tensor, optional) – the shape of the result. A tensor gives a nested tensor with one shape per row. Defaults to None, which gives a 1-D tensor.

  • dtype (dtype, optional) – the dtype to read the storage with. Defaults to None, which reads an untyped storage as torch.int64 and accepts a typed storage only if its dtype is the default dtype (torch.get_default_dtype()). Pass dtype to read another dtype.

  • device (device, str or int, optional) – None or "cpu". Defaults to None.

  • index (index, optional) – an index applied to the result. Defaults to None.

  • filename (str or Path, optional) – the file of the storage, if it has one and does not record it. Defaults to None.

  • handler – internal.

Raises:

RuntimeError – if the storage has a file and filename names another one.

Examples

>>> import os
>>> import tempfile
>>> import torch
>>> from tensordict import MemoryMappedTensor
>>> with tempfile.TemporaryDirectory() as tmpdir:
...     filename = os.path.join(tmpdir, "x.memmap")
...     _ = MemoryMappedTensor.from_tensor(torch.arange(6.0), filename=filename)
...     storage = torch.UntypedStorage.from_file(filename, shared=True, nbytes=24)
...     x = MemoryMappedTensor.from_storage(storage, dtype=torch.float32, shape=(2, 3))
...     print(x, x.filename == filename)
MemoryMappedTensor([[0., 1., 2.],
                    [3., 4., 5.]]) True
classmethod from_tensor(input, *, filename: Path | str = None, existsok: bool = False, copy_existing: bool = False, copy_data: bool = True, shape: Size | None = None)#

Returns a MemoryMappedTensor with a copy of the content of input.

If input is a MemoryMappedTensor, it is returned unchanged in two cases: filename is None and input has no file, or filename is the file of input (and input was not opened with mode="r"). A file-backed input with filename=None is copied to anonymous shared memory. In all other cases, a new MemoryMappedTensor is produced.

Parameters:

input (Tensor) – the tensor to copy. A nested tensor must have the torch.strided layout.

Keyword Arguments:

  • filename (str or Path, optional) – the file to write the data to. Defaults to None, which keeps the data in anonymous shared memory.

  • existsok (bool, optional) – if True, an existing file at filename is overwritten. If False, it raises an error. Defaults to False.

  • copy_existing (bool, optional) – if True, a MemoryMappedTensor with a file can be copied to another file. If False, this raises an error, so that data is not duplicated on disk by mistake. Defaults to False.

  • copy_data (bool, optional) – if False, the result has the shape and dtype of input but its content is not written. Defaults to True.

  • shape (Size or Tensor, optional) – the shape of the result, when it differs from that of input; input is broadcast to it. For a nested tensor, a tensor with the shape of each element, one per row. Defaults to None, which keeps the shape of input.

Returns:

A MemoryMappedTensor, which is input itself in the two cases above.

Raises:

  • RuntimeError – if input requires gradients, if input has a file, filename is another file and copy_existing is False, or if filename exists and existsok is False.

  • TypeError – if input is a NumPy array.

Examples

>>> import os
>>> import tempfile
>>> import torch
>>> from tensordict import MemoryMappedTensor
>>> with tempfile.TemporaryDirectory() as tmpdir:
...     filename = os.path.join(tmpdir, "tensor.memmap")
...     mmap = MemoryMappedTensor.from_tensor(torch.arange(3.0), filename=filename)
...     print(mmap)
...     print(MemoryMappedTensor.from_tensor(mmap, filename=filename) is mmap)
MemoryMappedTensor([0., 1., 2.])
True

split(split_size, dim=0)#

Splits the tensor into views of split_size, as torch.Tensor.split() does.

The parts are MemoryMappedTensors on the same storage, so they keep the file and can be pickled. Under torch.compile(), they are regular tensors.

unbind(dim)#

Removes a dimension and returns the slices along it, as torch.Tensor.unbind() does.

The slices are MemoryMappedTensors on the same storage, so they keep the file and can be pickled. Under torch.compile(), they are regular tensors. Unlike torch.Tensor.unbind(), dim has no default.

# TensorDictBase.sin

TensorDictBase.sin_() → Self

Applies [`torch.sin()`](https://docs.pytorch.org/docs/stable/generated/torch.sin.html#torch.sin) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

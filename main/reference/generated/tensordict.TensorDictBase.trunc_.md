# TensorDictBase.trunc

TensorDictBase.trunc_() → Self

Applies [`torch.trunc()`](https://docs.pytorch.org/docs/stable/generated/torch.trunc.html#torch.trunc) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

# TensorDictBase.cos

TensorDictBase.cos_() → Self

Applies [`torch.cos()`](https://docs.pytorch.org/docs/stable/generated/torch.cos.html#torch.cos) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

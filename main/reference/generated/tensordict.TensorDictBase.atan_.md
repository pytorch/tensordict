# TensorDictBase.atan

TensorDictBase.atan_() → Self

Applies [`torch.atan()`](https://docs.pytorch.org/docs/stable/generated/torch.atan.html#torch.atan) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

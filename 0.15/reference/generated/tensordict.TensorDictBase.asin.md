# TensorDictBase.asin

TensorDictBase.asin() → Self

Returns a new tensordict with [`torch.asin()`](https://docs.pytorch.org/docs/stable/generated/torch.asin.html#torch.asin) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

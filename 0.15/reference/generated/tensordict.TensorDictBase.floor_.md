# TensorDictBase.floor

TensorDictBase.floor_() → Self

Applies [`torch.floor()`](https://docs.pytorch.org/docs/stable/generated/torch.floor.html#torch.floor) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

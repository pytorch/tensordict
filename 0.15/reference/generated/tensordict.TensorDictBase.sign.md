# TensorDictBase.sign

TensorDictBase.sign() → Self

Returns a new tensordict with [`torch.sign()`](https://docs.pytorch.org/docs/stable/generated/torch.sign.html#torch.sign) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

# TensorDictBase.frac

TensorDictBase.frac() → Self

Returns a new tensordict with [`torch.frac()`](https://docs.pytorch.org/docs/stable/generated/torch.frac.html#torch.frac) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

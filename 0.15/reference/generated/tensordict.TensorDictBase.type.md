# TensorDictBase.type

TensorDictBase.type(*dst_type: [dtype](https://docs.pytorch.org/docs/stable/tensor_attributes.html#torch.dtype)*) → Self

Casts all tensors to `dst_type`.

Parameters:

**dst_type** ([*type*](https://docs.python.org/3/builtins/functions.html#type)*or**string*) - the desired type

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

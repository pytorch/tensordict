# TensorDictBase.floor

TensorDictBase.floor() → Self

Computes the [`floor()`](https://docs.pytorch.org/docs/stable/generated/torch.floor.html#torch.floor) value of each element of the TensorDict.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

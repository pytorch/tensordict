# TensorDictBase.exp

TensorDictBase.exp() → Self

Returns a new tensordict with [`torch.exp()`](https://docs.pytorch.org/docs/stable/generated/torch.exp.html#torch.exp) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

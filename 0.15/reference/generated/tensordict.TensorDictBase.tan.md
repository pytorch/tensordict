# TensorDictBase.tan

TensorDictBase.tan() → Self

Returns a new tensordict with [`torch.tan()`](https://docs.pytorch.org/docs/stable/generated/torch.tan.html#torch.tan) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

# TensorDictBase.neg

TensorDictBase.neg_() → Self

Applies [`torch.neg()`](https://docs.pytorch.org/docs/stable/generated/torch.neg.html#torch.neg) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

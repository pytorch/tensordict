# TensorDictBase.expm1

TensorDictBase.expm1() → Self

Returns a new tensordict with [`torch.expm1()`](https://docs.pytorch.org/docs/stable/generated/torch.expm1.html#torch.expm1) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

# TensorDictBase.ndimension

TensorDictBase.ndimension() → [int](https://docs.python.org/3/builtins/functions.html#int)

Returns the number of batch dimensions, the same as [`batch_dims`](tensordict.TensorDictBase.batch_dims.html#tensordict.TensorDictBase.batch_dims).

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

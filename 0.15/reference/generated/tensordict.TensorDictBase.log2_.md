# TensorDictBase.log2

TensorDictBase.log2_() → Self

Applies [`torch.log2()`](https://docs.pytorch.org/docs/stable/generated/torch.log2.html#torch.log2) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

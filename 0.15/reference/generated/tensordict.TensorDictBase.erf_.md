# TensorDictBase.erf

TensorDictBase.erf_() → Self

Applies [`torch.erf()`](https://docs.pytorch.org/docs/stable/generated/torch.erf.html#torch.erf) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

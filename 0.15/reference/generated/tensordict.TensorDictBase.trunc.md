# TensorDictBase.trunc

TensorDictBase.trunc() → Self

Returns a new tensordict with [`torch.trunc()`](https://docs.pytorch.org/docs/stable/generated/torch.trunc.html#torch.trunc) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

# TensorDictBase.log10

TensorDictBase.log10_() → Self

Applies [`torch.log10()`](https://docs.pytorch.org/docs/stable/generated/torch.log10.html#torch.log10) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

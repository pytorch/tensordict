# TensorDictBase.lgamma

TensorDictBase.lgamma() → Self

Returns a new tensordict with [`torch.lgamma()`](https://docs.pytorch.org/docs/stable/generated/torch.lgamma.html#torch.lgamma) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

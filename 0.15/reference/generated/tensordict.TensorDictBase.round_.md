# TensorDictBase.round

TensorDictBase.round_() → Self

Computes the [`round()`](https://docs.pytorch.org/docs/stable/generated/torch.round.html#torch.round) value of each element of the TensorDict in-place.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

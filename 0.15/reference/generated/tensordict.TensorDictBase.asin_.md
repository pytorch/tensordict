# TensorDictBase.asin

TensorDictBase.asin_() → Self

Computes the [`asin()`](https://docs.pytorch.org/docs/stable/generated/torch.asin.html#torch.asin) value of each element of the TensorDict in-place.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

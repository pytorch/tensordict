# TensorDictBase.erfc

TensorDictBase.erfc() → Self

Returns a new tensordict with [`torch.erfc()`](https://docs.pytorch.org/docs/stable/generated/torch.erfc.html#torch.erfc) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

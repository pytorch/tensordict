# TensorDictBase.sqrt

TensorDictBase.sqrt() → Self

Returns a new tensordict with [`torch.sqrt()`](https://docs.pytorch.org/docs/stable/generated/torch.sqrt.html#torch.sqrt) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

# TensorDictBase.sinh

TensorDictBase.sinh() → Self

Returns a new tensordict with [`torch.sinh()`](https://docs.pytorch.org/docs/stable/generated/torch.sinh.html#torch.sinh) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

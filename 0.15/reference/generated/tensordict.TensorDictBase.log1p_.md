# TensorDictBase.log1p

TensorDictBase.log1p_() → Self

Applies [`torch.log1p()`](https://docs.pytorch.org/docs/stable/generated/torch.log1p.html#torch.log1p) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

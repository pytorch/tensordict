# TensorDictBase.reciprocal

TensorDictBase.reciprocal_() → Self

Applies [`torch.reciprocal()`](https://docs.pytorch.org/docs/stable/generated/torch.reciprocal.html#torch.reciprocal) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

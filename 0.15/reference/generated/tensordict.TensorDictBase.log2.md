# TensorDictBase.log2

TensorDictBase.log2() → Self

Returns a new tensordict with [`torch.log2()`](https://docs.pytorch.org/docs/stable/generated/torch.log2.html#torch.log2) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

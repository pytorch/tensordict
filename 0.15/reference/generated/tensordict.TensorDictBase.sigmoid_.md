# TensorDictBase.sigmoid

TensorDictBase.sigmoid_() → Self

Computes the [`sigmoid()`](https://docs.pytorch.org/docs/stable/generated/torch.sigmoid.html#torch.sigmoid) value of each element of the TensorDict in-place.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

# TensorDictBase.log10

TensorDictBase.log10() → Self

Returns a new tensordict with [`torch.log10()`](https://docs.pytorch.org/docs/stable/generated/torch.log10.html#torch.log10) applied to every leaf.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).

# TensorDictBase.acos

TensorDictBase.acos_() → Self

Applies [`torch.acos()`](https://docs.pytorch.org/docs/stable/generated/torch.acos.html#torch.acos) to every leaf in place and returns `self`.

Every tensordict class and every tensorclass has this method. For the
other methods, see [Methods by task](../td.html#api-tensordict-methods).
